# 文本表名称核对

2026-11-16：核对当前 PC 日服初始底稿中的全部 56 张候选表。以底稿的字段解析结果、已有的 21 张文本导出，以及公开日服数据的字段结构确定名称。中文名用于显示，原始表名和替换范围标识保持原样。

公开数据依据：[arisu-archive/bluearchive-data](https://github.com/arisu-archive/bluearchive-data/tree/b1617a749602dacaee7fbb6587794e74c1eb1b98/ExcelDB)。这是移动端日服结构，用于交叉核对字段含义；本地 PC 底稿确认表是否存在及能否读取，不以两个客户端的行数相同为前提。

小游戏交叉核对：Concentration 的 max_card_pair_count / max_card_open_count 确认为翻牌配对；CCG 的 Card、StartDeckCard、condition_card 确认为卡牌构筑；Dream 的 dream_maker_days、action_point、parameter / ending_condition 确认为养成；RoadPuzzle 的 rail_set_reward_id 和 RailTile 确认为轨道解谜；TBG 的 default_item_dice_id、thema_map 与队伍配置确认为掷骰地图冒险。VoiceRoomException 的 costume_unique_id / linked_costume_unique_id 是服装之间的语音关联，不能译为房间语音。

部分表只有编号、资源路径或空字符串，不保存台词正文。此类名称明确使用“配置”或“资源”，避免与实际的文本表混淆。LocalizeSkill 与 LocalizeSkillNew 字段和部分内容重叠，使用“技能名称与说明”和“技能名称与说明（新版）”区分物理表，不假定前者已废弃。未来新增表保留原名，避免凭命名猜测用途。
