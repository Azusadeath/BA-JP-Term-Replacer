### 优化与修复

- 工具全名统一为 BA-JP-Term-Replacer，简称 BA-JPTR；启动程序改名为 BA-JP-Term-Replacer.exe，下载文件改名为 BA-JP-Term-Replacer.zip。
- 整理批量修改时增加全文重新定位：原位置失效后，在同一文本表内查找保存的完整原文。唯一匹配、目标未被占用且没有多条旧记录竞争时自动修复位置；同一位置的单条与批量修改一起移动，保留原有内容和优先级。部分修改保持原范围，完整覆盖且结果一致时才转为整表替换；保存前备份，支持撤销、重做。
- 细分整理后保留记录的原因，区分部分覆盖、跳过假名、原文变化、重复原文及定位冲突，日志提供对应处理方法。
- 工作区新增“来源表排序”，支持按首字母、修改时间或添加时间排列替换列表，默认按添加时间。仅调整显示顺序，保留词条执行优先级；排序设置和时间记录随备份保存、恢复。
- 查找、编辑和范围选择统一使用“文本表”名称，逐一核对现有 56 张表的中文名称和用途，明确区分台词正文与资源配置，纠正小游戏及语音配置等名称。
- 查找页的文本表按钮按名称长度保持紧凑，超长内容单行显示省略号；展开菜单按当前列表中最长的名称适配宽度。选择文本表窗口移除“刷新”，打开时自动读取。
- “编辑替换内容与范围”改名为“编辑批量修改”，左侧列表仅展示替换前内容，保持两行摘要；统一“编辑”“移除”“保存”等操作名称，保留 Ctrl、Shift 多选移除，保存操作保留图标。
- 正则模板直接展示随输入更新的替换前后示例；移除主表“命中”列及重复检测，简化空白、重复计数和说明文字，移除鼠标悬停提示。
- 未配置游戏目录时显示提示，目录设置固定保留在工具页。工作区备份按钮统一为“导出 / 恢复”，关于页将“构建时间”放入“构建与运行信息”。
- 零变化预览仅显示文字已一致的说明，隐藏空比较表格和重复计数；底部不再重复提示文字已与词表一致。“预览并应用”保留右下角位置及图标，“单条修改”按钮不再附带数量。
- 统一编辑、预览和“迁移旧版修改”核对窗口的按钮与布局，保留旧版单条及批量修改迁移、备份恢复、撤销与重做等功能；开发和发布工具统一使用 Rust xtask。
